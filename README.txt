HOW TO UPDATE YOUR WEBSITE
1. Open index.html in any text editor (or edit it directly on GitHub: click the file, then the pencil icon).
2. Scroll to the block marked "EDIT YOUR DETAILS HERE".
3. To add a certificate, video or photo: copy one line in that list, paste it below, change the text.
4. Upload photos/certificate scans into the "images" folder and write their path, e.g. "images/nptel.jpg".
5. Also change "Your Name" in the <title>, description and JSON-LD at the top (this is what Google reads).
6. Save / Commit. The live site updates in about a minute.
